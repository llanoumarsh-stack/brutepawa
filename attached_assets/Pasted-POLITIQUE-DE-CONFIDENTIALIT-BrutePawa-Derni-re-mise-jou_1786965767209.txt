POLITIQUE DE CONFIDENTIALITÉ

BrutePawa

Dernière mise à jour : 17 août 2026

BrutePawa accorde une grande importance à la protection de votre vie privée.

La présente Politique de confidentialité explique comment Brute, l'entité qui exploite BrutePawa, collecte, utilise, conserve, protège et partage les données personnelles lorsque vous utilisez BrutePawa, nos applications, notre site web et les fonctionnalités associées.

Cette Politique s'applique aux utilisateurs de BrutePawa dans le monde entier, sous réserve des règles obligatoires applicables dans leur pays ou région.

En utilisant BrutePawa, vous reconnaissez avoir pris connaissance de cette Politique de confidentialité.

---

01 — INTRODUCTION

1.1 Qui sommes-nous ?

Brute est l'entité responsable de BrutePawa et, selon les services concernés et la législation applicable, peut agir en qualité de responsable du traitement de vos données personnelles.

BrutePawa est une plateforme sociale permettant notamment aux utilisateurs de créer un profil, de communiquer, de partager des contenus, de rejoindre des communautés, de suivre d'autres utilisateurs et d'utiliser différentes fonctionnalités sociales.

Nous nous engageons à traiter vos données de manière transparente, proportionnée et sécurisée.

Lorsque la législation applicable l'exige, nous respectons notamment les principes et obligations prévus par les réglementations relatives à la protection des données personnelles, y compris le Règlement général sur la protection des données (RGPD) lorsqu'il est applicable.

1.2 Portée de cette Politique

Cette Politique s'applique aux données personnelles traitées dans le cadre :

- de l'application BrutePawa ;
- du site web BrutePawa ;
- de votre compte ;
- des publications ;
- des commentaires ;
- des messages ;
- des groupes et communautés ;
- des pages ;
- des fonctionnalités de création de contenu ;
- des diffusions en direct ;
- des fonctionnalités de créateurs ;
- des abonnements et services payants ;
- des systèmes de support et de signalement.

Cette Politique ne s'applique pas nécessairement aux services exploités indépendamment par des tiers auxquels BrutePawa peut renvoyer.

1.3 Nos principes

Nous nous efforçons de respecter les principes suivants :

- collecter uniquement les données nécessaires ;
- expliquer clairement pourquoi nous utilisons les données ;
- utiliser les données pour des finalités déterminées ;
- maintenir les données aussi exactes que possible ;
- protéger les données contre les accès non autorisés ;
- conserver les données uniquement pendant la durée nécessaire ;
- respecter les droits des utilisateurs ;
- améliorer continuellement nos pratiques de sécurité et de confidentialité.

Ces principes correspondent notamment aux principes fondamentaux de protection des données reconnus par le RGPD.

02 — DONNÉES QUE NOUS COLLECTONS

Nous pouvons collecter différentes catégories de données selon la manière dont vous utilisez BrutePawa.

2.1 Informations de compte

Lorsque vous créez un compte, nous pouvons collecter :

- nom ou nom d'affichage ;
- nom d'utilisateur ;
- adresse e-mail ;
- numéro de téléphone lorsque vous choisissez de l'utiliser ;
- mot de passe ou informations d'authentification protégées ;
- date de naissance ou âge lorsque nécessaire ;
- photo de profil ;
- pays ou région ;
- informations nécessaires à la vérification du compte.

Certaines informations peuvent être facultatives.

2.2 Informations de profil

Vous pouvez choisir d'ajouter à votre profil :

- photo ;
- biographie ;
- localisation générale ;
- centres d'intérêt ;
- liens ;
- informations publiques ;
- informations permettant aux autres utilisateurs de vous identifier ou de vous contacter.

Les informations que vous choisissez de rendre publiques peuvent être visibles par d'autres utilisateurs selon vos paramètres de confidentialité.

2.3 Contenus que vous créez

Lorsque vous utilisez BrutePawa, nous pouvons traiter les contenus que vous choisissez de publier ou de partager, notamment :

- textes ;
- photographies ;
- vidéos ;
- fichiers audio ;
- commentaires ;
- publications ;
- stories ;
- messages ;
- contenus de groupes ;
- contenus de pages ;
- diffusions en direct.

Le contenu que vous publiez peut contenir des données personnelles concernant vous-même ou d'autres personnes.

Vous devez donc vous assurer que vous disposez des droits nécessaires avant de publier des informations concernant une autre personne.

2.4 Données relatives à votre activité

Nous pouvons collecter des informations concernant votre utilisation de BrutePawa, notamment :

- comptes que vous suivez ;
- comptes qui vous suivent ;
- publications avec lesquelles vous interagissez ;
- likes ;
- commentaires ;
- partages ;
- recherches ;
- groupes ou communautés rejoints ;
- interactions avec les fonctionnalités ;
- paramètres sélectionnés ;
- signalements effectués ;
- préférences.

2.5 Données techniques

Lorsque vous utilisez BrutePawa, certains renseignements techniques peuvent être automatiquement générés ou collectés, notamment :

- adresse IP ;
- type d'appareil ;
- système d'exploitation ;
- version de l'application ;
- navigateur ;
- langue ;
- fuseau horaire ;

Certaines fonctionnalités peuvent nécessiter ou permettre l'utilisation de données de localisation.

Lorsque cela est applicable, nous vous demanderons les autorisations nécessaires.

Vous pouvez contrôler certaines autorisations directement depuis votre appareil.

Nous ne devons pas présenter une collecte de localisation comme active si la fonctionnalité correspondante n'est pas réellement utilisée par BrutePawa.

2.7 Données relatives aux paiements

Lorsque vous utilisez des fonctionnalités payantes, des abonnements, des cadeaux ou d'autres services nécessitant un paiement, certaines informations peuvent être traitées afin de permettre la transaction.

Selon le moyen de paiement utilisé, les informations de paiement peuvent être directement traitées par un prestataire de paiement tiers.

Brute peut recevoir certaines informations relatives à la transaction, telles que :

- statut du paiement ;
- montant ;
- devise ;
- date de la transaction ;
- identifiant de transaction ;
- informations nécessaires à la gestion des remboursements.

Nous ne devons pas stocker les données bancaires complètes si celles-ci sont directement traitées par un prestataire spécialisé.

Droit d'opposition

Vous pouvez, dans certaines circonstances, vous opposer à certains traitements de vos données, notamment lorsque la base juridique applicable le permet.

Lorsque les conditions légales sont réunies, vous pouvez demander à recevoir certaines données dans un format structuré et couramment utilisé.

Retrait du consentement

Lorsque nous traitons des données sur la base de votre consentement, vous pouvez retirer ce consentement à tout moment.

07 — DONNÉES DES ENFANTS

BrutePawa accorde une attention particulière à la protection des enfants et des adolescents.

BrutePawa ne doit pas être utilisé par des personnes n'ayant pas l'âge minimum requis par la législation applicable.

Lorsque la loi impose un âge supérieur à notre âge général minimum, cet âge supérieur s'applique.

Nous ne cherchons pas volontairement à collecter davantage de données personnelles auprès d'enfants que ce qui est nécessaire au fonctionnement légal du service.

Si nous apprenons qu'un compte a été créé en violation des règles d'âge applicables, nous pouvons prendre des mesures, notamment supprimer ou restreindre le compte et les données associées lorsque cela est légalement approprié.

Si vous pensez qu'un enfant utilise BrutePawa en violation des règles applicables, vous pouvez nous contacter.

10 — CONSERVATION DES DONNÉES

Nous conservons les données personnelles uniquement pendant la durée nécessaire aux finalités pour lesquelles elles sont traitées, sauf lorsqu'une durée plus longue est nécessaire ou autorisée par la loi.

La durée de conservation peut dépendre :

- de la durée d'existence de votre compte ;
- de la nature des données ;
- de la finalité du traitement ;
- de nos obligations légales ;
- de nos obligations comptables ou fiscales ;
- de la sécurité ;
- de la prévention des fraudes ;
- de la résolution des litiges.

Lorsque vous supprimez votre compte, nous lançons les processus applicables de suppression ou d'anonymisation.

Certaines copies peuvent rester temporairement dans les systèmes de sauvegarde ou être conservées lorsque cela est nécessaire pour respecter une obligation légale, prévenir une fraude, protéger la sécurité ou faire valoir un droit.

Nous ne conservons pas les données personnelles indéfiniment sans raison légitime.
